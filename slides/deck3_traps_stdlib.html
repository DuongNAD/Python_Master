02 collections.Counter: Đếm siêu tốc & Top K

Counter là lớp con của dict được tối ưu chuyên biệt cho việc thống kê tần suất xuất hiện.

Đếm và tìm K phần tử xuất hiện nhiều nhất

Python
from collections import Counter

s = "abracadabra"
cnt = Counter(s)
# Counter({'a': 5, 'b': 2, 'r': 2, 'c': 1, 'd': 1})

# Lấy top 2 phần tử xuất hiện nhiều nhất:
print(cnt.most_common(2))
# [('a', 5), ('b', 2)]

Phép toán số học trên Counter

Có thể cộng, trừ trực tiếp hai bộ đếm:

Python
c1 = Counter(a=3, b=1)
c2 = Counter(a=1, b=2, c=1)

# Cộng dồn:
tong = c1 + c2 # Counter({'a': 4, 'b': 3, 'c': 1})

# Kiểm tra chuỗi đảo chữ (Anagram) trong 1 dòng:
def la_anagram(s1, s2):
    return Counter(s1) == Counter(s2)
Tốc độ phòng thi: Thay vì viết vòng lặp 5 dòng với d.get(), Counter(arr) hoàn thành trong 1 dòng và chạy bằng mã C nguyên bản, nhanh gấp 3 lần.

03 collections.deque & defaultdict

⚠️ BẪY THỜI GIAN CHẠY (TLE): list.pop(0) mất O(N) thời gian!

Khi dùng danh sách thông thường làm hàng đợi (Queue), arr.pop(0) buộc mọi phần tử phía sau phải dịch chuyển sang trái 1 ô. Nếu N = 100,000, thuật toán sẽ bị quá thời gian (TLE) ngay lập tức!

deque: Hàng đợi hai đầu O(1)

Python
from collections import deque

q = deque([1, 2, 3])
q.append(4)       # Thêm vào đuôi: O(1)
q.appendleft(0)   # Thêm vào đầu: O(1)
first = q.popleft() # Lấy khỏi đầu: O(1)
last = q.pop()      # Lấy khỏi đuôi: O(1)

defaultdict: Tự động khởi tạo

Python
from collections import defaultdict

# Không bao giờ bị KeyError:
adj = defaultdict(list) # Đồ thị kề
adj["Hà Nội"].append("Hải Phòng")

cnt = defaultdict(int)  # Mặc định là 0
cnt["view"] += 1

04 heapq: Hàng đợi ưu tiên (Min-Heap & Max-Heap)

Module heapq trong Python mặc định cài đặt Min-Heap: Phần tử nhỏ nhất luôn nằm ở vị trí h[0] trong thời gian O(1).

Min-Heap cơ bản

Python
import heapq

h = [5, 1, 8, 3, 2]
heapq.heapify(h)    # Biến list thành heap: O(N)
heapq.heappush(h, 0) # Thêm phần tử: O(log N)
min_val = heapq.heappop(h) # Lấy phần tử nhỏ nhất: O(log N)
# min_val = 0, đỉnh mới h[0] = 1

Mô phỏng Max-Heap bằng số âm

Python không có sẵn Max-Heap, ta đổi dấu âm khi đẩy vào và lấy ra:

Python
max_h = []
for x in [5, 1, 8, 3]:
    heapq.heappush(max_h, -x) # Đảo dấu

# Lấy phần tử LỚN NHẤT:
max_val = -heapq.heappop(max_h) # 8
Thủ thuật Top-K: heapq.nlargest(k, arr) và heapq.nsmallest(k, arr) giúp lấy K phần tử cực trị nhanh hơn sắp xếp toàn bộ danh sách khi K << N.

05 itertools & bisect: Sinh tổ hợp & Chặt nhị phân

itertools: permutations & combinations

Python
import itertools

# Tổ hợp chập 2 (không phân biệt thứ tự):
list(itertools.combinations([1, 2, 3], 2))
# [(1, 2), (1, 3), (2, 3)]

# Hoán vị chập 2 (có phân biệt thứ tự):
list(itertools.permutations([1, 2], 2))
# [(1, 2), (2, 1)]

# Tích Descartes (ghép mọi cặp):
list(itertools.product(["A", "B"], [1, 2]))
# [('A', 1), ('A', 2), ('B', 1), ('B', 2)]

bisect: Tìm kiếm nhị phân có sẵn O(log N)

Python
import bisect

# BẮT BUỘC MẢNG PHẢI SẮP XẾP TRƯỚC:
arr = [10, 20, 30, 40, 50]

# bisect_left: vị trí đầu tiên >= x
idx = bisect.bisect_left(arr, 30) # 2

# bisect_right: vị trí đầu tiên > x
idx = bisect.bisect_right(arr, 30) # 3

# insort: chèn vào mảng mà vẫn giữ thứ tự
bisect.insort(arr, 25) # [10, 20, 25, 30, 40, 50]

07 Bẫy 04: Xóa phần tử khi đang duyệt danh sách

Một trong những câu bẫy kinh điển nhất trong phần Debugging.

✗ Code SAI: Sửa danh sách đang duyệtBỏ sót phần tử
Python
nums = [1, 2, 2, 3, 4]
for x in nums:
    if x == 2:
        nums.remove(x)
print(nums)
# KẾT QUẢ SAI: [1, 2, 3, 4] (Số 2 thứ hai KHÔNG BỊ XÓA!)
✓ Code ĐÚNG: Lọc bằng Comprehension hoặc duyệt bản saoChuẩn
Python
# Cách 1: List comprehension tạo mảng mới (Khuyên dùng)
nums = [x for x in nums if x != 2]

# Cách 2: Duyệt trên bản sao nums[:]
for x in nums[:]:
    if x == 2:
        nums.remove(x)
Giải thích cơ chế ngầm: Khi xóa phần tử tại vị trí 1, phần tử thứ hai bị trượt về vị trí 1. Nhưng con trỏ vòng lặp của Python tiếp tục bước sang vị trí 2, dẫn đến việc bỏ qua hoàn toàn phần tử vừa trượt tới!

08 Bẫy 05: list.sort() trả về None

Phương thức .sort() và .reverse() của list thay đổi mảng tại chỗ và trả về None để nhắc nhở lập trình viên.

✗ Code SAI: Gán biến bằng a.sort()Nhận None
Python
arr = [3, 1, 2]
sorted_arr = arr.sort()
print(sorted_arr) # None!
# sorted_arr[0] -> TypeError: 'NoneType' object is not subscriptable
✓ Code ĐÚNG: Dùng sorted() hoặc gọi riêngChuẩn
Python
# Cách 1: Dùng sorted() trả về mảng mới
sorted_arr = sorted(arr)

# Cách 2: Gọi sort() riêng rồi dùng mảng gốc
arr.sort()
# arr bây giờ đã là [1, 2, 3]
Quy tắc 3 giây phát hiện: Trong bài Debugging, hễ thấy dòng nào có dạng x = y.sort() hoặc x = y.reverse() hoặc x = y.append(...) thì 100% dòng đó chính là dòng bị lỗi!

09 Bẫy 10: Dùng 'is' thay vì '==' để so sánh số

CPython chỉ cache sẵn các số nguyên nhỏ từ -5 đến 256 trong bộ nhớ để tái sử dụng.

Hành vi kỳ lạ của toán tử 'is'

Python
x = 100
y = 100
print(x is y) # True (do nằm trong [-5 .. 256])

a = 1000
b = 1000
print(a is b) # FALSE! (2 đối tượng khác nhau trong RAM!)

Phân biệt rạch ròi

  • == so sánh GIÁ TRỊ NỘI DUNG: 1000 == 1000 luôn là True.
  • is so sánh ĐỊA CHỈ VÙNG NHỚ (identity): id(a) == id(b).
  • Chỉ dùng is cho các hằng số: x is None, x is True, x is False.
