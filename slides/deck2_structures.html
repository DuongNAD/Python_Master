02 Bẫy tử thần: [[0] * m] * n khi tạo Ma trận

Đây là lỗi sai phổ biến nhất trong đề thi khi thí sinh cần tạo bảng kích thước N hàng × M cột.

✗ Code SAI: [[0] * m] * nNhân bản con trỏ

Phép nhân * n chỉ nhân bản N lần cùng 1 địa chỉ danh sách con:

Python
matrix = [[0] * 3] * 3
matrix[0][0] = 99
# KẾT QUẢ TAI HỌA: CẢ 3 HÀNG ĐỀU BỊ ĐỔI THÀNH 99!
# [[99, 0, 0], [99, 0, 0], [99, 0, 0]]
✓ Code ĐÚNG: List ComprehensionTạo mảng con mới

Mỗi vòng lặp tạo ra một danh sách hàng hoàn toàn độc lập trong RAM:

Python
matrix = [[0] * 3 for _ in range(3)]
matrix[0][0] = 99
# CHUẨN XÁC: Chỉ đúng ô (0, 0) bị thay đổi:
# [[99, 0, 0], [0, 0, 0], [0, 0, 0]]
Quy tắc bất di bất dịch: KHÔNG BAO GIỜ dùng toán tử * ngoài cùng để tạo danh sách lồng nhau! Luôn dùng [[0] * m for _ in range(n)].

03 Kỹ thuật duyệt Ma trận: Hàng, Cột & Đường chéo

Với ma trận vuông cấp N × N, tọa độ ô là (r, c) với 0 ≤ r, c < N:

1. Duyệt theo cột

Cột cố định ở vòng ngoài, hàng chạy ở vòng trong:

Python
for c in range(m):
    col_sum = sum(matrix[r][c] for r in range(n))

2. Đường chéo chính

Chỉ số hàng bằng chỉ số cột: r == c:

Python
main_diag = [matrix[i][i] for i in range(n)]

3. Đường chéo phụ

Tổng chỉ số bằng N - 1: r + c == N - 1:

Python
anti_diag = [matrix[i][n - 1 - i] for i in range(n)]
Ứng dụng cờ vua / Đặt hậu: Hai ô (r1, c1) và (r2, c2) cùng đường chéo khi và chỉ khi abs(r1 - r2) == abs(c1 - c2) hoặc r1 + c1 == r2 + c2 và r1 - c1 == r2 - c2.

04 Chuyển vị ma trận (Transpose) & Xoay 90 độ

Chuyển vị là biến hàng thành cột: matrix[r][c] đổi thành matrix[c][r].

Chuyển vị 1 dòng với zip(*matrix)

Python
matrix = [
    [1, 2, 3],
    [4, 5, 6]
]
# zip(*matrix) gom các phần tử cùng cột lại:
transpose = [list(col) for col in zip(*matrix)]
# [[1, 4], [2, 5], [3, 6]]

Xoay ma trận 90 độ theo chiều kim đồng hồ

Công thức: Đảo ngược thứ tự các hàng (lật trên xuống dưới), sau đó Chuyển vị!

Python
def xoay_90(m):
    # Lật ngược các hàng rồi chuyển vị:
    return [list(col) for col in zip(*m[::-1])]

# Xoay ngược chiều kim đồng hồ:
def xoay_nguoc_90(m):
    return [list(col) for col in zip(*m)][::-1]
Thủ thuật: Chỉ cần nhớ 1 công thức [list(col) for col in zip(*m[::-1])] là bạn giải quyết mọi bài xoay hình ảnh hoặc xoay bảng cờ 90° trong 10 giây!

05 Ma trận xoắn ốc: Kỹ thuật 4 con trỏ biên

07 Từ điển (Dict): Tra cứu O(1) & get vs setdefault

Dictionary trong Python là bảng băm (Hash Table) với tốc độ thêm, xóa, kiểm tra k in d chỉ mất O(1) thời gian.

✗ Lỗi KeyError khi truy cập trực tiếp

Python
counts = {}
# counts["apple"] += 1 
# SẬP CHƯƠNG TRÌNH: KeyError: 'apple'

✓ Xử lý an toàn: get() & setdefault()

Python
counts = {}
# get(key, default): nếu chưa có thì trả về 0
counts["apple"] = counts.get("apple", 0) + 1

# setdefault(key, default): tự tạo list rỗng nếu chưa có
nhom = {}
nhom.setdefault("lop_A", []).append("Nam")

Sắp xếp Dictionary theo Giá trị (Value)

Muốn tìm top phần tử xuất hiện nhiều nhất không cần import thư viện ngoài:

Python
freq = {"a": 5, "b": 12, "c": 2}
# Sắp xếp giảm dần theo số lần xuất hiện:
sorted_freq = sorted(freq.items(), key=lambda item: item[1], reverse=True)
# [('b', 12), ('a', 5), ('c', 2)]

08 Tập hợp (Set) & Tối ưu tìm kiếm O(1)

Set chỉ lưu các phần tử duy nhất (không trùng lặp) và phần tử phải là Hashable (bất biến: int, str, tuple; cấm list, dict).

Các phép toán tập hợp cực nhanh

Python
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}

A | B   # Hợp (Union): {1, 2, 3, 4, 5, 6}
A & B   # Giao (Intersection): {3, 4}
A - B   # Hiệu (Difference - có trong A mà ko có B): {1, 2}
A ^ B   # Hiệu đối xứng (có trong 1 trong 2): {1, 2, 5, 6}

Tối ưu hóa từ O(N) sang O(1)

Kiểm tra x in list mất O(N), nhưng x in set chỉ mất O(1):

Python
# Nếu danh sách cấm có 100,000 từ:
tu_cam_set = set(danh_sach_cam) # Tiền xử lý O(N)
for tu in van_ban:
    if tu in tu_cam_set: # O(1) mỗi lần kiểm tra!
        print("Phát hiện từ cấm!")
Bẫy khởi tạo Set rỗng: Viết s = {} là tạo Dictionary rỗng! Muốn tạo Set rỗng bắt buộc phải viết s = set().

10 Điều khiển luồng: Vòng lặp for...else kỳ diệu

Trong Python, vòng lặp for và while có thể đi kèm một khối else. Khối else chỉ chạy khi vòng lặp hoàn thành tự nhiên mà KHÔNG bị lệnh break ngắt!

Cách truyền thống (Dùng cờ hiệu flag)

Python
found = False
for x in arr:
    if x == target:
        found = True
        break
if not found:
    print("Không tìm thấy")

Cách Pythonic với for...else

Python
for x in arr:
    if x == target:
        print("Tìm thấy!")
        break
else:
    # Chỉ chạy khi vòng lặp duyệt hết mà không break
    print("Không tìm thấy")
Ứng dụng kiểm tra số nguyên tố: Duyệt for i in range(2, int(n**0.5) + 1): if n % i == 0: return False rồi đặt return True ở khối else!

11 Bẫy tử thần: Tham số mặc định là Mutable (def f(arr=[]))

Trong Python, giá trị mặc định của hàm được khởi tạo đúng 1 lần duy nhất khi hàm được định nghĩa, chứ không phải mỗi lần hàm được gọi!

✗ Code SAI: def f(x, arr=[])Dữ liệu bị lưu tích lũy
Python
def them(x, arr=[]):
    arr.append(x)
    return arr

print(them(1)) # [1]
print(them(2)) # [1, 2] (BỊ DÍNH LẠI DỮ LIỆU CŨ!)
✓ Code ĐÚNG: Gán mặc định NoneTạo mới mỗi lần gọi
Python
def them(x, arr=None):
    if arr is None:
        arr = [] # Tạo mảng mới tinh trong hàm
    arr.append(x)
    return arr

print(them(1)) # [1]
print(them(2)) # [2] (Độc lập 100%)
Quy tắc vàng: Tuyệt đối không bao giờ dùng list, dict, hoặc set làm tham số mặc định của hàm. Luôn đặt = None và kiểm tra if param is None: param = [].

12 OOP cho COS Pro Level 1 (Chung kết)

Đề thi Chung kết Level 1 thường yêu cầu bạn hoàn thiện hoặc viết một class để mô phỏng nghiệp vụ (quản lý kho, giỏ hàng, thẻ ngân hàng, game thẻ bài).

Bộ khung Class tiêu chuẩn trong đề thi

Python
class SinhVien:
    def __init__(self, mssv, ten, diem):
        self.mssv = mssv
        self.ten = ten
        self.diem = diem
        
    def __str__(self):
        # Trả về chuỗi khi gọi print(obj)
        return f"{self.mssv} - {self.ten}: {self.diem}đ"
        
    def __lt__(self, other):
        # Less Than: Cho phép dùng obj1 < obj2 hoặc arr.sort() tự động!
        # Xếp theo điểm giảm dần, nếu bằng điểm xếp theo tên:
        if self.diem != other.diem:
            return self.diem > other.diem
        return self.ten < other.ten
Thủ thuật: Cài đặt phương thức __lt__(self, other) giúp danh sách các đối tượng tự động được sắp xếp chuẩn xác khi bạn gọi students.sort() mà không cần viết hàm key=lambda phức tạp!
