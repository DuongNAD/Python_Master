04 Phép chia lấy dư (%) với số âm & Tọa độ xoay vòng

Trong C++ hay Java, -7 % 3 = -1. Nhưng trong Python, kết quả của phép modulo luôn cùng dấu với số chia!

Toán học của Python

Python định nghĩa: a % b = a - b * (a // b)

Với -7 % 3:

  • -7 // 3 = -3 (làm tròn xuống số nguyên nhỏ hơn)
  • -7 - 3 * (-3) = -7 + 9 = 2

Kết quả: -7 % 3 == 2 (Số dư dương [0 .. b-1])

Ứng dụng đỉnh cao: Đi lùi trên vòng tròn

Khi một kim đồng hồ có 12 số, đang ở vị trí 2 mà lùi 5 bước:

Python
pos = 2
buoc_lui = 5
n = 12
# Không cần viết if pos < 0: pos += n
pos_moi = (pos - buoc_lui) % n # (2 - 5) % 12 = -3 % 12 = 9!
print(pos_moi) # Ra đúng 9
Quy tắc phòng thi: Khi cần di chuyển tiến/lùi theo chu kỳ N phần tử, công thức luôn là (cur + step) % N, bất kể step là số âm hay dương!

10 Danh sách (List) & Slicing bước âm đỉnh cao

Cú pháp cắt lát: arr[start : stop : step]. Chỉ số lấy từ start đến stop - 1.

Các lát cắt kinh điển

Python
a = [10, 20, 30, 40, 50, 60]

a[1:4]     # [20, 30, 40] (từ 1 đến 3)
a[:3]      # [10, 20, 30] (3 phần tử đầu)
a[-2:]     # [50, 60] (2 phần tử cuối)
a[::2]     # [10, 30, 50] (bước nhảy 2)
a[::-1]    # [60, 50, 40, 30, 20, 10] (ĐẢO NGƯỢC)

Slicing bước âm: a[stop : start : -1]

Khi step < 0, start phải lớn hơn stop:

Python
# Đảo ngược danh sách không tốn thêm biến:
s = "racecar"
is_palindrome = (s == s[::-1]) # True

# Gán lát cắt thay thế tại chỗ (in-place):
nums = [1, 2, 3, 4, 5]
nums[1:4] = [99, 99] # [1, 99, 99, 5]
Mẹo phòng thi: Cắt lát không bao giờ báo lỗi IndexError kể cả khi chỉ số vượt quá độ dài danh sách (ví dụ a[:1000] khi len(a) = 5 vẫn trả về toàn bộ a).

11 List Comprehension: Cú pháp & Kỹ thuật lọc

Thay thế vòng lặp for + append() bằng biểu thức 1 dòng chạy nhanh gấp 2 lần bằng mã C ngầm.

Python
# Cú pháp 1: Lọc điều kiện if (chỉ lấy phần tử thỏa mãn)
chan = [x for x in range(10) if x % 2 == 0] # [0, 2, 4, 6, 8]

# Cú pháp 2: Biến đổi if - else (áp dụng cho mọi phần tử)
nhan_dien = ["CHẴN" if x % 2 == 0 else "LẺ" for x in range(5)]
# ['CHẴN', 'LẺ', 'CHẴN', 'LẺ', 'CHẴN']

# Cú pháp 3: Làm phẳng ma trận 2D (Flatten)
matrix = [[1, 2, 3], [4, 5, 6]]
flat = [x for row in matrix for x in row] # [1, 2, 3, 4, 5, 6]
⚠️ Bẫy đề thi: List Comprehension xóa Max/Min

Nếu đề bài: "Bỏ 1 điểm cao nhất và 1 điểm thấp nhất của ban giám khảo" mà bạn viết: [x for x in scores if x != max_s and x != min_s] thì khi có 2 điểm 10 trùng nhau, nó sẽ xóa sạch cả 2 điểm 10!

Cách viết đúng: Sắp xếp rồi cắt lát bỏ phần tử đầu và cuối: sorted(scores)[1:-1]

13 sorted() vs sort() & Sắp xếp đa khóa

Phân biệt: list.sort() thay đổi mảng gốc tại chỗ và trả về None; còn sorted(list) trả về mảng mới.

Sắp xếp đa tiêu chí với Tuple: key = lambda x: (tiêu_chí_1, tiêu_chí_2)

Đề bài: "Sắp xếp học sinh theo điểm giảm dần, nếu cùng điểm thì xếp theo tuổi tăng dần, nếu cùng tuổi thì xếp theo tên chữ cái."

Python
students = [
    {"ten": "An", "diem": 8.5, "tuoi": 20},
    {"ten": "Bình", "diem": 9.0, "tuoi": 19},
    {"ten": "Cường", "diem": 8.5, "tuoi": 19}
]

# Dùng dấu âm (-) để đảo ngược chiều sắp xếp số:
students.sort(key=lambda s: (-s["diem"], s["tuoi"], s["ten"]))
# Kết quả: Bình (9.0) -> Cường (8.5, 19 tuổi) -> An (8.5, 20 tuổi)
⚠️ BẪY TỬ THẦN: Dấu trừ (-) không dùng được cho chuỗi ký tự!

Nếu muốn sắp xếp tên chuỗi giảm dần, không được viết -s["ten"] (sẽ báo TypeError: bad operand type for unary -: 'str'). Giải pháp: sắp xếp 2 lần với thuật toán Stable Sort của Python (Timsort) hoặc dùng thư viện.

14 Bẫy tham chiếu: Shallow Copy vs Deep Copy

Trong Python, biến chỉ là chiếc thẻ bài (nhãn) trỏ tới vùng nhớ. Phép gán b = a KHÔNG tạo ra mảng mới!

Bẫy Shallow Copy với mảng 2 chiều

Python
a = [[1, 2], [3, 4]]
b = a.copy() # hoặc a[:] - CHỈ COPY TẦNG 1!
b[0][0] = 99
print(a[0][0]) # IN RA 99! (Mảng a gốc bị hỏng!)

Giải pháp Deep Copy chuẩn xác

Python
import copy
a = [[1, 2], [3, 4]]
b = copy.deepcopy(a) # Nhân bản toàn bộ mọi tầng
# Hoặc dùng list comprehension:
b = [row[:] for row in a]
b[0][0] = 99
print(a[0][0]) # IN RA 1 (a gốc vẫn an toàn!)
Cách ghi nhớ nhanh: Với mảng 1 chiều chứa số nguyên, a.copy() hay a[:] là đủ. Nhưng với ma trận 2D hoặc danh sách chứa dict/list lồng nhau, bắt buộc dùng copy.deepcopy().
