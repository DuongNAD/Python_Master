02 Bài 1.01 · Đếm số nguyên âm trong chuỗi

💡 Đề bài nói gì? (Ngôn ngữ bình dân)

Đếm xem trong câu có bao nhiêu nguyên âm: a, e, i, o, u. Không phân biệt chữ hoa hay chữ thường (nghĩa là 'A' hay 'a' đều tính là 1).

⚡ Bản chất thuật toán

Hạ toàn bộ chuỗi về chữ thường bằng s.lower() để chỉ cần so với chuỗi "aeiou". Duyệt từng ký tự, nếu ky_tu in "aeiou" thì tăng biến dem += 1.

Code chuẩn & Vị trí điền khuyết Đạt điểm tối đa
Python
def dem_nguyen_am(s: str):
    nguyen_am = "aeiou"
    dem = 0
    for ky_tu in s.lower():      # <--- Chỗ trống (1): s.lower()
        if ky_tu in nguyen_am:   # <--- Chỗ trống (2): ky_tu in nguyen_am
            dem += 1
    return dem

⚠️ Bẫy thường gặp

  • Quên s.lower(): Nếu viết for ky_tu in s:, các ký tự viết hoa như 'A', 'E' sẽ không khớp với "aeiou" và bị đếm sót!
  • Dùng toán tử == thay vì in: Viết ky_tu == nguyen_am là so sánh 1 ký tự với cả chuỗi 5 chữ cái (luôn False). Bắt buộc dùng in.

03 Bài 1.02 · Chuẩn hóa họ tên người

💡 Đề bài nói gì? (Ngôn ngữ bình dân)

Biến chuỗi gõ lộn xộn " nGUYEN anh duong " thành họ tên chuẩn "Nguyen Anh Duong": bỏ sạch dấu cách thừa ở đầu, cuối và giữa; viết hoa chữ đầu mỗi từ, còn lại viết thường.

⚡ Bản chất thuật toán (Tam tấu thần thánh)

1. s.split() (không tham số) tự động dọn sạch mọi khoảng trắng thừa.
2. tu.capitalize() biến chữ đầu thành HOA, các chữ sau thành THƯỜNG.
3. " ".join(...) dán các từ lại với đúng 1 dấu cách duy nhất.

Code chuẩn & Điền chỗ trống 3 Chỗ trống
Python
def chuan_hoa_ten(s):
    cac_tu = s.split()                            # <--- Chỗ trống (1): s.split()
    ket_qua = [tu.capitalize() for tu in cac_tu]  # <--- Chỗ trống (2): tu.capitalize()
    return " ".join(ket_qua)                      # <--- Chỗ trống (3): " ".join(ket_qua)

⚠️ Phân biệt bẫy capitalize() vs title()

Hàm tu.capitalize() chỉ viết hoa chữ cái đầu tiên và ép các chữ cái sau thành chữ thường ('nGUYEN' -> 'Nguyen').
Nếu dùng s.title() gặp từ có dấu nháy như "o'connor" sẽ bị biến thành "O'Connor" (viết hoa cả sau dấu nháy). Viết List Comprehension với tu.capitalize() là chuẩn mực 100%.

04 Bài 1.03 · Tính tổng các chữ số của số nguyên

💡 Đề bài nói gì? (Ngôn ngữ bình dân)

Cho một số nguyên n (có thể âm, ví dụ -4567). Hãy cộng từng chữ số của nó lại: $4 + 5 + 6 + 7 = 22$.

⚡ Bản chất thuật toán (Bóc tách chữ số)

1. n = abs(n): Khử ngay dấu âm để không bị sai phép toán số học.
2. n % 10: Lấy chữ số hàng đơn vị.
3. n = n // 10: Cắt bỏ chữ số hàng đơn vị vừa lấy. Lặp cho đến khi n == 0.

Code chuẩn & 3 Điểm khuyết Chuẩn O(log10(N))
Python
def tong_chu_so(n):
    n = abs(n)
    tong = 0
    while n > 0:          # <--- Chỗ trống (1): n > 0
        tong += n % 10    # <--- Chỗ trống (2): n % 10
        n = n // 10       # <--- Chỗ trống (3): n // 10
    return tong

⚠️ Bẫy số âm trong Python

Trong Python, phép chia số âm làm tròn xuống sàn: (-5) % 10 = 5, nhưng (-5) // 10 = -1 (bị kẹt vòng lặp vô hạn!).
Vì vậy, lệnh n = abs(n) ở đầu hàm là bắt buộc sống còn trước khi vào vòng lặp while n > 0.

05 Bài 1.04 · Tìm số lớn thứ hai trong các giá trị phân biệt

💡 Đề bài nói gì? (Ngôn ngữ bình dân)

Tìm số lớn nhì trong mảng nhưng chỉ tính các giá trị khác nhau. Ví dụ [5, 5, 4] thì số lớn nhất là 5, số lớn nhì là 4 (chứ không phải 5). Nếu mảng không đủ 2 số khác nhau (như [7, 7, 7]) thì trả về None.

⚡ Bản chất thuật toán

1. phan_biet = set(arr): Lọc sạch mọi phần tử trùng lặp.
2. Nếu len(phan_biet) < 2: Không đủ 2 số khác nhau ➔ return None.
3. phan_biet.remove(max(phan_biet)): Bắn hạ số lớn nhất.
4. return max(phan_biet): Số lớn nhất còn lại chính là số lớn thứ hai ban đầu!

Code chuẩn & Điền chỗ trống set + remove max
Python
def max_thu_hai(arr):
    phan_biet = set(arr)               # <--- Chỗ trống (1): set(arr)
    if len(phan_biet) < 2:
        return None
    phan_biet.remove(max(phan_biet))   # <--- Chỗ trống (2): max(phan_biet)
    return max(phan_biet)

⚠️ Tại sao không sort rồi lấy arr[-2]?

Nếu làm ngây thơ sorted(arr)[-2] trên mảng [5, 5, 4], mảng sắp xếp là [4, 5, 5] và vị trí kế cuối vẫn là 5 (SAI!).
Vì vậy, bắt buộc phải đưa qua set() để triệt tiêu trùng lặp trước khi xét thứ hạng.

06 Bài 1.05 · Bảng đếm tần suất 1 dòng với dict.get()

💡 Đề bài nói gì? (Ngôn ngữ bình dân)

Đếm xem mỗi phần tử xuất hiện bao nhiêu lần và lưu vào từ điển (dict). Đề yêu cầu: Chỉ được dùng đúng 1 dòng code trong vòng lặp.

⚡ Bản chất tuyệt chiêu dict.get(x, 0) + 1

Hàm dict.get(key, default) trả về giá trị của key nếu đã có, hoặc trả về default nếu chưa có.
Do đó bang[x] = bang.get(x, 0) + 1 tự động khởi tạo bằng 1 khi gặp lần đầu, và cộng thêm 1 ở các lần sau mà không lo lỗi KeyError!

Code chuẩn 1 dòng trong vòng lặp Tuyệt chiêu Pythonic
Python
def dem_tan_suat(arr):
    bang = {}
    for x in arr:
        bang[x] = bang.get(x, 0) + 1   # <--- Chỗ trống (1): bang.get(x, 0) + 1
    return bang

⚠️ Bẫy KeyError tử thần

Nếu bạn viết bang[x] += 1: Ở lần đầu tiên gặp x, khóa x chưa hề tồn tại trong từ điển, Python sẽ ném ngay lỗi KeyError: x và chương trình sụp đổ ngay lập tức!

07 Bài 1.06 · Đảo ngược thứ tự các từ trong câu

💡 Đề bài nói gì? (Ngôn ngữ bình dân)

Đảo thứ tự các TỪ trong câu: "hom nay troi dep" -> "dep troi nay hom". Lưu ý là đảo các từ chứ không phải đảo từng chữ cái (chữ "dep" vẫn là "dep", không phải "ped").

⚡ Bản chất thuật toán

1. s.split() cắt câu thành danh sách các từ sạch: ['hom', 'nay', 'troi', 'dep'].
2. cac_tu.reverse() đảo ngược danh sách tại chỗ.
3. " ".join(cac_tu) nối lại thành một chuỗi duy nhất.

Code chuẩn & Điền chỗ trống cac_tu.reverse()
Python
def dao_thu_tu_tu(s):
    cac_tu = s.split()
    cac_tu.reverse()             # <--- Chỗ trống (1): cac_tu.reverse()
    return " ".join(cac_tu)

⚠️ Bẫy hàm trả về None của list.reverse()

08 Bài 1.07 · Kiểm tra chuỗi đối xứng Palindrome (Lọc isalnum)

💡 Đề bài nói gì? (Ngôn ngữ bình dân)

Kiểm tra xem chuỗi đọc xuôi có giống đọc ngược không. Nhưng đề yêu cầu: Bỏ qua mọi dấu câu, dấu cách và không phân biệt hoa thường! Ví dụ "A man, a plan, a canal: Panama" là True.

⚡ Bản chất thuật toán (Lọc sạch rồi lật ngược)

1. sach = [c.lower() for c in s if c.isalnum()]: Chỉ giữ lại chữ cái và chữ số, hạ về chữ thường.
2. return sach == sach[::-1]: So sánh mảng sạch với bản lật ngược của nó.

Code chuẩn & Điền chỗ trống c.isalnum() + sach[::-1]
Python
def la_doi_xung(s):
    # Lọc ký tự chữ/số và đưa về chữ thường
    sach = [c.lower() for c in s if c.isalnum()]  # <--- Chỗ trống (1): c.lower()
    return sach == sach[::-1]                     # <--- Chỗ trống (2): sach[::-1]

⚠️ Ký tự isalnum() là gì?

c.isalnum() là viết tắt của is alpha-numeric: trả về True nếu c là chữ cái (a-z, A-Z) HOẶC chữ số (0-9).
Mọi dấu cách ' ', phẩy ',', hai chấm ':', chấm hỏi '?' đều bị loại bỏ sạch sẽ!

09 Bài 1.08 · Gộp 2 Dict cộng dồn giá trị (Không đè gốc)

💡 Đề bài nói gì? (Ngôn ngữ bình dân)

Gộp 2 từ điển lại với nhau. Nếu có khóa trùng nhau thì CỘNG giá trị của chúng lại. Đề bài cấm: Không được sửa đổi dict a hay dict b gốc!

⚡ Bản chất thuật toán

1. ket_qua = a.copy(): Tạo một bản sao độc lập của a.
2. Duyệt qua từng cặp (khoa, gia_tri) trong b.items().
3. Cộng dồn: ket_qua[khoa] = ket_qua.get(khoa, 0) + gia_tri.

Code chuẩn & 3 Vị trí điền khuyết a.copy() + b.items()
Python
def gop_dict_cong_don(a, b):
    ket_qua = a.copy()                                    # <--- Chỗ trống (1): a.copy()
    for khoa, gia_tri in b.items():                       # <--- Chỗ trống (2): b.items()
        ket_qua[khoa] = ket_qua.get(khoa, 0) + gia_tri   # <--- Chỗ trống (3): ket_qua.get(khoa, 0) + gia_tri
    return ket_qua

⚠️ Bẫy dùng phép gán ket_qua = a

Nếu viết ket_qua = a: Hai biến cùng trỏ vào 1 vùng nhớ duy nhất! Khi bạn sửa ket_qua["y"], dict a ban đầu cũng bị sửa theo, vi phạm thẳng yêu cầu "Không được sửa a" của đề bài!
Bắt buộc dùng a.copy() hoặc dict(a).

10 Bài 1.09 · Lọc số nguyên tố & Định lý O(√N)

💡 Đề bài nói gì? (Ngôn ngữ bình dân)

Lọc ra tất cả các số nguyên tố trong mảng và giữ nguyên thứ tự ban đầu. Số nguyên tố là số $> 1$ chỉ chia hết cho 1 và chính nó.

⚡ Tại sao điều kiện là i * i <= n?

Nếu $n = a \times b$, thì chắc chắn 1 trong 2 số phải $\le \sqrt{n}$. Do đó, ta chỉ cần thử chia từ 2 đến $\sqrt{n}$ (tức i * i <= n). Nếu không chia hết thì $n$ chắc chắn là số nguyên tố! Giúp giảm độ phức tạp từ $O(N)$ xuống $O(\sqrt{N})$.

Code chuẩn & Điền chỗ trống i * i <= n
Python
def loc_so_nguyen_to(arr):
    def la_nguyen_to(n):
        if n < 2:
            return False
        i = 2
        while i * i <= n:        # <--- Chỗ trống (1): i * i <= n
            if n % i == 0:
                return False
            i += 1
        return True

    return [x for x in arr if la_nguyen_to(x)]  # <--- Chỗ trống (2)

⚠️ Bẫy số < 2

Số 0, số 1 và các số âm KHÔNG PHẢI là số nguyên tố theo định nghĩa toán học!
Điều kiện if n < 2: return False ở đầu hàm chặn đứng mọi số âm, 0 và 1 trước khi vào vòng lặp.

11 Bài 1.10 · Nén chuỗi Run-Length Encoding (RLE)

💡 Đề bài nói gì? (Ngôn ngữ bình dân)

Đếm các ký tự lặp liên tiếp và gom lại: "aaabbc" -> "a3b2c1". Chuỗi rỗng "" thì trả về "".

⚡ Bản chất thuật toán

Lưu ky_tu_truoc = s[0] và dem = 1. Duyệt từ ký tự thứ hai for c in s[1:]:
- Nếu c == ky_tu_truoc: dem += 1.
- Nếu đổi ký tự: Đóng gói nhóm cũ ket_qua.append(ky_tu_truoc + str(dem)), chuyển sang theo dõi c mới.

Code chuẩn & Vị trí đóng gói Bẫy nhóm cuối
Python
def nen_chuoi(s):
    if not s:
        return ""
    ket_qua = []
    ky_tu_truoc = s[0]
    dem = 1
    for c in s[1:]:                               # <--- Chỗ trống (1): s[1:]
        if c == ky_tu_truoc:
            dem += 1
        else:
            ket_qua.append(ky_tu_truoc + str(dem)) # <--- Chỗ trống (2)
            ky_tu_truoc = c
            dem = 1
    ket_qua.append(ky_tu_truoc + str(dem))       # BẮT BUỘC: Đóng gói nhóm cuối!
    return "".join(ket_qua)

⚠️ BẪY TỬ THẦN: Quên nhóm cuối cùng

Khi vòng for kết thúc, ký tự cuối cùng (như chữ 'c' trong "aaabbc") vẫn đang nằm trong ky_tu_truoc và dem chưa được đẩy vào ket_qua!
Dòng ket_qua.append(ky_tu_truoc + str(dem)) ở ngoài vòng for là bắt buộc để không làm rơi mất đuôi kết quả!

12 Bài 1.11 · Xoay mảng sang phải k bước (Negative Slicing)

💡 Đề bài nói gì? (Ngôn ngữ bình dân)

Đẩy cả mảng dịch sang phải k bước, phần tử nào bị tràn ra đuôi sẽ quay lại đầu mảng. Giá trị k có thể lớn hơn cả độ dài mảng (ví dụ mảng dài 3 mà xoay 7 bước).

⚡ Bản chất thuật toán

1. k = k % len(arr): Rút gọn chu kỳ vòng tròn (mảng dài 5, xoay 7 bước cũng như xoay 2 bước).
2. Lấy k phần tử ở đuôi văng sang đầu: arr[-k:].
3. Ghép với phần còn lại ở đầu trượt sang: arr[:-k].

Code chuẩn & Cắt lát âm arr[-k:] + arr[:-k]
Python
def xoay_phai(arr, k):
    if not arr:
        return []
    k = k % len(arr)                                # <--- Chỗ trống (1): k % len(arr)
    return arr[-k:] + arr[:-k] if k else list(arr)  # <--- Chỗ trống (2)

⚠️ Bẫy k = 0 trong slicing âm

Nếu k = 0 mà bạn cắt arr[-0:] thì -0 bằng 0, tức arr[0:] (lấy cả mảng), cộng với arr[:-0] (mảng rỗng) vẫn chạy được, nhưng đoạn code chuẩn dùng if k else list(arr) để xử lý dứt khoát và trả về bản sao list mới an toàn 100%!

13 Bài 1.12 · Two Sum O(N) — Đi tìm mảnh ghép còn thiếu

💡 Đề bài nói gì? (Ngôn ngữ bình dân)

Tìm một cặp vị trí (i, j) sao cho arr[i] + arr[j] == target. Yêu cầu chạy trong thời gian O(N) (cấm duyệt 2 vòng lặp lồng nhau $O(N^2)$).

⚡ Bản chất thuật toán (Sổ tay ghi nhớ)

Khi đang đứng ở số $x$ tại vị trí $j$, ta cần tìm số can = target - x.
Tra cứu trong sổ da_gap: nếu can in da_gap, lấy ngay cặp (da_gap[can], j)! Nếu chưa có, ghi nhớ vào sổ da_gap[x] = j.

Code chuẩn & 3 Vị trí điền khuyết O(N) Hash Map
Python
def tim_cap_tong(arr, target):
    da_gap = {}                 # gia_tri -> chi so
    for j, x in enumerate(arr):
        can = target - x        # <--- Chỗ trống (1): target - x
        if can in da_gap:       # <--- Chỗ trống (2): can in da_gap
            return (da_gap[can], j)
        da_gap[x] = j           # <--- Chỗ trống (3): j
    return None

⚠️ Tại sao Chỗ trống (3) lại là j?

Dict da_gap có nhiệm vụ ánh xạ: Giá trị số ➔ Vị trí (chỉ số) của nó.
Số hiện tại là x, đang đứng ở vị trí j, nên phải gán da_gap[x] = j để các phần tử đi sau có thể lấy được chỉ số của x khi cần!

14 Bài 1.13 · Sắp xếp đa tiêu chí & Tuyệt chiêu dấu trừ -diem

💡 Đề bài nói gì? (Ngôn ngữ bình dân)

Xếp hạng danh sách học sinh theo 3 tiêu chí: Điểm GIẢM dần; nếu bằng điểm thì Tuổi TĂNG dần; nếu bằng cả hai thì Tên theo bảng chữ cái A-Z. Trả về danh sách tên.

⚡ Bí kíp Tuple Key & Đảo dấu

Python so sánh Tuple từ trái sang phải và mặc định là TĂNG DẦN.
Muốn diem giảm dần? Thêm dấu trừ: -h["diem"]! Khi đó điểm 9.0 thành -9.0 (nhỏ nhất ➔ đứng đầu bảng).
Key hoàn chỉnh: (-h["diem"], h["tuoi"], h["ten"]).

Code chuẩn & Điền chỗ trống Multi-key Lambda
Python
def xep_hang_hoc_sinh(hoc_sinh):
    # Sắp xếp đa khóa bằng Tuple
    da_sap = sorted(hoc_sinh, key=lambda h: (-h["diem"], h["tuoi"], h["ten"])) # <--- Chỗ trống (1)
    return [h["ten"] for h in da_sap]                                          # <--- Chỗ trống (2)

⚠️ Chỗ trống (2) trả về cái gì?

Đọc kỹ câu cuối của đề bài: "Trả về list tên".
Nếu bạn viết return da_sap (trả về cả danh sách dict) thì sẽ bị chấm 0 điểm!
Phải trích xuất riêng trường tên: [h["ten"] for h in da_sap].

15 Bài 1.14 · Đổi cơ số hệ 2..16 với bảng ký tự 0123456789ABCDEF

💡 Đề bài nói gì? (Ngôn ngữ bình dân)

Đổi một số nguyên không âm $n$ sang hệ cơ số $b$ (từ hệ nhị phân 2 đến hệ thập lục phân 16). Ví dụ đổi 255 sang hệ 16 thì ra "FF", số 0 thì ra "0".

⚡ Bản chất thuật toán (Chia lấy dư liên tiếp)

1. Lấy số dư: n % b, tra vào bảng ký tự chu_so[n % b].
2. Cắt bỏ: n = n // b.
3. Đảo ngược: Vì số dư đầu tiên là hàng đơn vị, nên danh sách thu được bị ngược, phải dùng "".join(reversed(ket_qua))!

Code chuẩn & 3 Điểm khuyết chu_so[n % b] + reversed
Python
def doi_co_so(n, b):
    if n == 0:
        return "0"
    chu_so = "0123456789ABCDEF"
    ket_qua = []
    while n > 0:
        ket_qua.append(chu_so[n % b])         # <--- Chỗ trống (1): chu_so[n % b]
        n = n // b                           # <--- Chỗ trống (2): n // b
    return "".join(reversed(ket_qua))        # <--- Chỗ trống (3): "".join(reversed(ket_qua))

⚠️ Tại sao phải có reversed()?

Khi đổi số 13 sang hệ 2:
- Lần 1: 13 % 2 = 1 (đây là số ở hàng $2^0$, tận cùng bên phải).
- Lần 2: 6 % 2 = 0 (hàng $2^1$).
- Lần 3: 3 % 2 = 1 (hàng $2^2$).
- Lần 4: 1 % 2 = 1 (hàng $2^3$).
Mảng thu được là ['1', '0', '1', '1']. Khi đảo ngược lại ta mới được số đúng là "1101"!

16 Bài 1.15 · Kiểm tra dấu ngoặc hợp lệ bằng Ngăn Xếp (Stack)

💡 Đề bài nói gì? (Ngôn ngữ bình dân)

Kiểm tra xem các cặp ngoặc (), [], {} có đóng mở đúng quy tắc không. Ví dụ "{[()]}" là True; còn "([)]" là False vì đóng lộn xộn.

⚡ Bản chất cơ chế Ngăn xếp (LIFO)

- Gặp ngoặc mở ([{: Nhét vào đỉnh stack ngan_xep.append(c).
- Gặp ngoặc đóng )]}: Rút đỉnh ra so sánh ngan_xep.pop() != cap[c]. Lệch hoặc stack rỗng là False ngay!
- Hết chuỗi: Stack phải sạch bóng len(ngan_xep) == 0.

Code chuẩn & 3 Điểm khuyết Stack LIFO Cổ điển
Python
def ngoac_hop_le(s):
    cap = {")": "(", "]": "[", "}": "{"}
    ngan_xep = []
    for c in s:
        if c in "([{":
            ngan_xep.append(c)                     # <--- Chỗ trống (1): c
        elif c in cap:
            if not ngan_xep or ngan_xep.pop() != cap[c]: # <--- Chỗ trống (2)
                return False
    return len(ngan_xep) == 0                      # <--- Chỗ trống (3): len(ngan_xep) == 0

⚠️ Tại sao Chỗ trống (3) không phải là return True?

Nếu chuỗi đầu vào là "(((" (toàn mở mà không hề có đóng): Vòng for sẽ chạy hết mà không hề gặp ngoặc đóng nào, nếu bạn viết return True thì chuỗi thiếu đóng này sẽ bị chấm là hợp lệ (SAI HOÀN TOÀN!).
Bắt buộc kiểm tra len(ngan_xep) == 0 để đảm bảo mọi ngoặc mở đều đã được đóng hết.
