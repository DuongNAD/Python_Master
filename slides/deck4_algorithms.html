01 Bản đồ ước lượng thuật toán theo kích thước N

Trong 1 giây, Python thực hiện được khoảng 10⁷ đến 5×10⁷ phép tính. Khi đọc đề, hãy nhìn kích thước N đầu tiên:

Kích thước N Độ phức tạp mục tiêu Thuật toán tương ứng
N ≤ 20 O(2ᴺ) hoặc O(N!) Quay lui (Backtracking), sinh mọi hoán vị/tổ hợp với itertools
N ≤ 100 O(N³) hoặc O(N²) Duyệt 2-3 vòng lặp lồng nhau, kiểm tra ma trận cơ bản
N ≤ 5,000 O(N²) Quy hoạch động 2D, hai vòng for, thuật toán kiểm tra cặp
N ≤ 100,000 O(N log N) hoặc O(N) Hai con trỏ, Cửa sổ trượt, Prefix Sum, Sort, Heap, BFS/DFS, Đếm Dict
N ≥ 10⁹ O(log N) hoặc O(1) Tìm kiếm nhị phân (Binary Search the Answer), Công thức toán học

02 Thuật toán 01: Hai con trỏ (Two Pointers)

Khi nào dùng: Mảng đã sắp xếp tăng dần, cần tìm 2 vị trí có tổng đúng bằng target trong thời gian O(N), bộ nhớ O(1).

Mẫu 01 (MAU_CODE.md) — Chuẩn ≤ 15 dòng
def two_sum_sorted(arr, target):
    l, r = 0, len(arr) - 1
    while l < r:
        s = arr[l] + arr[r]
        if s == target:
            return l, r
        elif s < target:
            l += 1
        else:
            r -= 1
    return -1, -1

03 Thuật toán 02: Cửa sổ trượt độ dài cố định K

Khi nào dùng: Tìm tổng hoặc trung bình lớn nhất của dãy con liên tiếp gồm đúng K phần tử. Tránh tính lại sum() tốn O(K) mỗi bước!

Mẫu 02 (MAU_CODE.md) — Chuẩn ≤ 15 dòng
def max_sum_subarray(arr, k):
    if len(arr) < k: return 0
    cur = max_s = sum(arr[:k])
    for i in range(k, len(arr)):
        cur += arr[i] - arr[i - k]  # Thêm phần tử mới vào, trừ phần tử cũ đi
        max_s = max(max_s, cur)
    return max_s

05 Thuật toán 03: Mảng tiền tố (Prefix Sum 1D & 2D)

Khi nào dùng: Cần trả lời Q truy vấn tính tổng đoạn con từ chỉ số L đến R. Nếu tính thủ công mất O(Q × N), mảng tiền tố giảm xuống O(1) mỗi truy vấn!

Công thức 1D Prefix Sum

Mảng pref có độ dài N + 1 với pref[0] = 0:

pref[i] = pref[i-1] + arr[i-1]

Tổng đoạn [L .. R]: pref[R + 1] - pref[L]

Python
arr = [2, 4, 1, 7, 5]
pref = [0]
for x in arr:
    pref.append(pref[-1] + x)
# pref = [0, 2, 6, 7, 14, 19]
# Tổng đoạn [1..3] (4+1+7):
s = pref[4] - pref[1] # 14 - 2 = 12

Prefix Sum 2D trên Ma trận

Tính tổng hình chữ nhật con từ (r1, c1) đến (r2, c2):

Tổng = pref[r2+1][c2+1] - pref[r1][c2+1] - pref[r2+1][c1] + pref[r1][c1]

06 Thuật toán 05: Tìm kiếm nhị phân & Chặt kết quả

Tìm kiếm nhị phân chia đôi không gian tìm kiếm mỗi bước, đạt tốc độ cực hạn O(log N).

Binary Search cơ bản

Mẫu 06 (MAU_CODE.md)
def binary_search(arr, target):
    l, r = 0, len(arr) - 1
    while l <= r:
        mid = (l + r) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            l = mid + 1
        else:
            r = mid - 1
    return -1

Khi bài toán hỏi: "Tìm giá trị K NHỎ NHẤT / LỚN NHẤT thỏa mãn điều kiện" và hàm điều kiện có tính đơn điệu (Monotonicity):

def bs_answer(low, high):

07 Thuật toán 06: Hợp nhất các khoảng (Merge Intervals)

Khi nào dùng: Xếp lịch phòng họp, tính tổng thời gian làm việc, tìm khoảng thời gian bị trùng lắp.

Mẫu 08 (MAU_CODE.md) — Chuẩn ≤ 15 dòng
def merge_intervals(intervals):
    if not intervals: return []
    # BƯỚC 1: Bắt buộc sắp xếp theo thời điểm bắt đầu
    intervals.sort(key=lambda x: x[0])
    merged = [intervals[0]]
    
    # BƯỚC 2: Duyệt và gộp khoảng nếu trùng nhau
    for cur in intervals[1:]:
        prev = merged[-1]
        if cur[0] <= prev[1]: # Có giao nhau
            prev[1] = max(prev[1], cur[1])
        else:
            merged.append(cur)
    return merged
Thử nghiệm nhanh: Với [[1, 3], [2, 6], [8, 10], [15, 18]], khoảng [1, 3] và [2, 6] giao nhau thành [1, 6]. Kết quả: [[1, 6], [8, 10], [15, 18]].

Ngăn xếp vào sau ra trước (LIFO). Ứng dụng: Kiểm tra biểu thức dấu ngoặc, tính toán hậu tố Ba Lan (RPN), và Monotonic Stack.

Mẫu 09 (MAU_CODE.md) — Chuẩn ≤ 15 dòng
def ngoac_hop_le(s):
    pairs = {')': '(', ']': '[', '}': '{'}
    stack = []
    for c in s:
        if c in pairs.values():
            stack.append(c)
        elif c in pairs:
            if not stack or stack.pop() != pairs[c]:
                return False
    return len(stack) == 0

10 Thuật toán 10: Quy hoạch động (Dynamic Programming)

Giải bài toán lớn bằng cách chia thành các bài toán con gối nhau và lưu kết quả lại trong mảng memoization.

DP 1D: Leo cầu thang (Climbing Stairs)

Mỗi bước có thể đi 1 hoặc 2 bậc. Số cách leo n bậc:

Mẫu 13 (MAU_CODE.md)
def climb_stairs(n):
    if n <= 2: return n
    dp = [0] * (n + 1)
    dp[1], dp[2] = 1, 2
    for i in range(3, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]
    return dp[n]

DP 2D: Đường đi có tổng lớn nhất trên lưới

Chỉ được đi xuống dưới hoặc sang phải:

Mẫu 14 (MAU_CODE.md)
def min_path_sum(grid):
    R, C = len(grid), len(grid[0])
    dp = [[0]*C for _ in range(R)]
    dp[0][0] = grid[0][0]
    for c in range(1, C): dp[0][c] = dp[0][c-1] + grid[0][c]
    for r in range(1, R): dp[r][0] = dp[r-1][0] + grid[r][0]
    for r in range(1, R):
        for c in range(1, C):
            dp[r][c] = min(dp[r-1][c], dp[r][c-1]) + grid[r][c]
    return dp[R-1][C-1]

11 Thuật toán 11: Sàng số nguyên tố Eratosthenes

Tìm toàn bộ số nguyên tố từ 2 đến N trong thời gian cực nhanh O(N log log N).

Mẫu 15 (MAU_CODE.md) — Chuẩn ≤ 15 dòng
def sieve(n):
    if n < 2: return []
    is_prime = [True] * (n + 1)
    is_prime[0] = is_prime[1] = False
    for i in range(2, int(n**0.5) + 1):
        if is_prime[i]:
            # Đánh dấu các bội số của i bắt đầu từ i*i
            for j in range(i * i, n + 1, i):
                is_prime[j] = False
    return [i for i, prime in enumerate(is_prime) if prime]
Tối ưu điểm thưởng: Điểm mấu chốt để đạt chuẩn O(N log log N) là vòng lặp trong bắt đầu từ i * i thay vì 2 * i, vì các bội số nhỏ hơn đã bị các ước số trước đó đánh dấu!
